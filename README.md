# Manguyá-SAC
Landing page y web app interactiva para Manguyá SAC, marca de néctar artesanal de Mango Kent y Maracuyá. Incluye mezclador de sabor, carrito de pedidos y checkout por WhatsApp.
# 🥭 Manguyá — Néctar Artesanal de Mango y Maracuyá

## 📌 Resumen del Proyecto Académico
**Manguyá** es una marca de néctar artesanal elaborada con frutas 100% naturales (Mango Kent y Maracuyá de huerto). Esta Landing Page y Web App ha sido desarrollada como un prototipo funcional e interactivo para la asignatura de **Administración y Marketing**.

---

## 🚀 Funcionalidades Principales
1. **Catálogo de Productos:** Presentaciones de 330ml (S/ 3.50) y 1 Litro (S/ 9.00).
2. **Mezclador de Sabor Interactivo:** Permite al usuario calibrar las proporciones de Mango vs. Maracuyá con descripción dinámica de notas de cata.
3. **Carrito de Compras y Checkout:** Proceso de pedido completo con captura de datos de entrega.
4. **Geolocalización Interactiva:** Mapa integrado con Leaflet.js (mosaicos Esri) para que el cliente marque el punto exacto de envío.
5. **Despacho Automático por WhatsApp:** Genera el mensaje formateado y codificado directamente hacia el número +51 918591764 sin truncamiento de texto.
6. **Comprobante de Pedido en PDF:** Descarga automática de boleta de compra utilizando `jsPDF`.
